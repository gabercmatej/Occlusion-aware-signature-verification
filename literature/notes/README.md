# Literature Notes

Create one Markdown file per paper. Use the starter files as a template.

Minimum sections:

1. Citation and link.
2. Exact task and threat model.
3. Dataset and writer split.
4. Architecture and loss.
5. Metrics and threshold protocol.
6. Main contribution.
7. Weaknesses or comparability concerns.
8. Relevance to occluded signature verification.
9. One concrete experiment enabled by the paper.
