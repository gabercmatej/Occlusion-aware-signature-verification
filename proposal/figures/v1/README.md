# Proposal figures version 1

These five original figures are included in proposal_v1.0.docx and proposal_v1.0.pdf.

1. `01-practical-problem.png` — stamped query, illustrative cleaning, comparison with an independently written fictional reference.
2. `02-visibility-comparison.png` — natural variation between references and queries, visible-detail zooms and qualitative regional influence.
3. `03-literature-map.png` and `.svg` — the nine reviewed papers and their roles in the proposed comparisons.
4. `04-complete-system.png` and `.svg` — the proposed system, including original-query preservation, optional cleaning and reliability-aware regional scoring.
5. `05-architecture-candidates.png` and `.svg` — the shared comparison setup, two representative extractors and the regional fusion experiment.

Figures 1 and 2 were generated and revised with the built-in image-generation tool. The cleaned query shares its underlying observation with the stamped query; the clean reference is a different signing instance with natural within-writer variation. Both figures are fictional illustrations, not actual restoration or verification outputs.

Figures 3–5 were drawn as editable vector diagrams to keep labels and arrows precise. The SVG files are their editable masters; the high-resolution PNGs are embedded in Word. Module choices and layer counts remain proposed experiments.

The final image prompts, generation mode and diagram specifications are saved in `generation-record.json`. No API/CLI fallback was used.
