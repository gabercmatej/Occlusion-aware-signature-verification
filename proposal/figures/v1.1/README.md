# Proposal illustrations v1.1

Five raster illustrations used in the v1.1 draft and preserved in both language versions of the current v1.2 proposal.

1. Practical problem: approved demo, unchanged.
2. Visibility-aware comparison: approved demo, unchanged. Reference and query are different signing instances.
3. Literature overview: original scientific illustration connecting the nine reviewed papers.
4. Proposed system: paired regional comparison, query visibility, optional restoration, and aggregation across references.
5. Architecture candidates: shared encoder setup, CNN and CNN–transformer alternatives, regional score fusion.

All illustrations use the built-in image generator. Final generation and edit prompts are in generation-record.json. The user's architecture screenshot was a visual style reference. These images are conceptual demos and do not report experimental outcomes. Layer counts, backbones and exact implementation details remain provisional. Figures 1–2 have short demo captions in the document.
