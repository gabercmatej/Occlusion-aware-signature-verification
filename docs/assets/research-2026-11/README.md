# Current conceptual diagrams

Prepared 11 November 2026 from `BUILD_PLAN.md` and the second research review.
These diagrams describe planned behaviour and experiments, not implementation
completion, measured results or established novelty. They contain no signatures
or customer data.

- `01-current-pipeline`: mandatory query cleaning, provenance, separate reference
  input, and similarity / evidence coverage / review outputs.
- `02-research-questions`: H1 and H2, their controlled comparisons, and supporting
  cleaning and transfer questions. The uncleaned evaluation control is pending
  owner approval.
- `03-development-roadmap`: early delivery, research, conditional extensions and
  portfolio / thesis preparation. The diagram is a grouping, not a dependency
  graph; the build plan contains the milestone dependencies.

PNG files are embedded in the public README; SVG files are editable vector
exports. Reproduce all six assets with an existing Matplotlib installation:

```sh
python3 docs/assets/research-2026-11/render.py
```

Historical generated proposal illustrations remain under `proposal/figures/`.
